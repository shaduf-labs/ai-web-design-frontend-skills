Skill radar · checked 18 September 2026

Seven frontend jobs. One review needs the real flow.

Choose the bottleneck first: concept-led visual build, visual direction, a flag-heavy React component, deliberate interface motion, a captured product-flow audit, a code-first UI review, or React/Next performance. Every listing is source-pinned. None is a pool-tested result.

Fast decision: Can someone click through the relevant journey and capture it? Start with Product Design Audit. Have files but no runnable flow? Choose Web Design Guidelines. Need a visual target before code? Use one of the visual lanes.

Stack by phase, not by hype

When the real problem isStart withDo not mistake it for
A high-visibility surface needs a visual targetFrontend App Builder if you can approve a concept and inspect a renderA measured quality result
The brief lacks visual directionFrontend Design before codeA replacement for product strategy
A live journey needs reviewProduct Design Audit with the actual captured flowProof of full accessibility
Files need focused reviewWeb Design Guidelines, then React Best Practices where it fitsProof the result is fast or visually right

Before you install: record target agent, scope, upstream revision, local edits, update review, and the proof resource. A flow audit needs a real journey and screenshots; a concept-led build needs approval and browser comparison.
