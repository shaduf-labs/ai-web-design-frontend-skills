Skill radar · checked 16 September 2026

Five frontend jobs. One adoption gate people skip.

Pick the bottleneck first: visual direction, a flag-heavy React component, deliberate interface motion, a UI review, or React/Next performance. Then decide where the instruction belongs. Every listing is source-pinned. None is a pool-tested result.

Fast decision: new landing page or dashboard? Start with Frontend Design. Seven booleans on one React component? Try React Composition Patterns. Motion that should explain navigation or a state change? Use React View Transitions. Review and performance still belong after there is code to inspect.

Choose the job, then the skill

Strong fit

Frontend Design

Use this for a new page, dashboard, or substantial visual refresh when the brief needs an intentional direction before code.

Needs
A concrete audience, product job, and constraints. A screenshot loop if your environment supports one.
Watch for
It is a creative instruction set, not your product strategy or existing design system. We read it; we did not test it.
Source
Anthropic skills, commit 41bbe19 · Apache-2.0 folder licence · rechecked 16 September 2026.
Conditional fit

React Composition Patterns

Use this when a React component has become a switchboard of boolean props, render callbacks, and hidden state.

Needs
A React component API worth refactoring. React 19-specific guidance only applies on React 19 or later.
Watch for
Its source is not a visual-design system. A third-party report identifies a lifted-state example to inspect before copying; its proposed correction remains unmerged.
Source
Vercel Agent Skills 063bee94 · skill metadata 1.0.0 · MIT.
Conditional fit

React View Transitions

Use this when motion should explain a route, shared element, list reorder, or a state appearing or disappearing.

Needs
A React or Next.js setup with the required ViewTransition support, plus reduced-motion and unsupported-browser checks.
Watch for
Skip decorative motion with no spatial or state meaning. A regular setState does not activate React ViewTransition.
Source
Vercel Agent Skills 063bee94 · skill metadata 1.0.0 · MIT.
Conditional fit

Web Design Guidelines

Use this after implementation to ask an agent for a terse UI review with file-and-line findings.

Needs
The files to review and network access to retrieve Vercel's current guideline set.
Watch for
Its package is pinned here, but its rules are fetched fresh. Record which rules were used; a clean output is not an accessibility test.
Source
Vercel Agent Skills 063bee94 · skill metadata 1.0.0 · MIT collection.
Conditional fit

Vercel React Best Practices

Use this for React or Next.js pages when bundle size, waterfalls, rendering, or re-renders are part of the job.

Needs
A React or Next.js codebase. It is not a general visual-design skill.
Watch for
The source also points to a full compiled guide. Prefer the relevant rules first; we have not measured its context cost in any agent.
Source
Vercel Agent Skills 063bee94 · skill metadata 1.0.0 · MIT.

Stack by phase, not by hype

The interface has no point of viewFrontend Design before codeA replacement for your product brief or design system
The component API is becoming flags and special casesReact Composition Patterns during refactoringA reason to rewrite a stable small component
Navigation or a state change needs continuityReact View Transitions after the interaction is clearDecorative animation or a cross-browser acceptance check
Code is already in placeWeb Design Guidelines, then React Best Practices when the stack fitsProof that the result is accessible, fast, or visually right

This sequence is a pool recommendation. It is not a controlled comparison.

Before you install: does this skill belong with this project?

Target: name the agent you will use. “Portable” is not a result or compatibility verdict.

Scope: keep an instruction in the project when it carries this product's design-system or acceptance assumptions; use a global default only when you want the same workflow across projects.

Change record: preserve the upstream URL and revision beside local edits. Review an upstream update before it overwrites a modified workflow.

The open skills CLI documents agent targets and project/global scopes. We did not install a listed skill or test these paths in Codex.
