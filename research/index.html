Evidence log

Why these listings exist.

26 September 2026 · Catalogue expansion · Meaningful change

One direction for the real screen.

Added PaulRBerg Frontend Design for an existing or substantial screen that needs one project-bound direction, local-system fidelity, and rendered inspection. Its mutable source, browser dependency, Codex loading, and outcome are untested by this pool.

25 September 2026 · Catalogue expansion · Meaningful change

Choose a visual direction before you build.

Added OpenAI Product Design Ideate for three image-based directions before prototype work. It needs plugin availability, a minimum brief, references, Image Gen, and a human choice. The mutable source and its outcome are untested by this pool.

24 September 2026 · Adoption gate · Meaningful change

A detailed frontend workflow is not ready if its package metadata fails.

Held Snowe UI Skill outside the catalogue because GitHub currently reports a YAML error in its SKILL.md frontmatter. We did not install it or test host behavior. Check package readiness before workflow fit.

23 September 2026 · Catalogue expansion · Meaningful change

Make the visual decision before you ask Codex to apply it.

Added source-pinned Wenkang Frontend Design for a real screen or defined concept that needs human visual choices, element annotations, and an exported decision packet before implementation. The local preview is not proof that the live route matches. No pool run was performed.

22 September 2026 · Catalogue expansion · Meaningful change

A design skill needs a complete state model.

Added source-pinned PracticalSwan Frontend Design 2.0 as a conditional path for substantial product work that needs explicit system context, complete states, responsive checks, and rendered verification. Its protocol is author guidance, not a pool result test.

21 September 2026 · Catalogue expansion · Meaningful change

QA needs the right browser surface.

Added OpenAI Frontend Testing & Debugging for a named rendered change or bug flow. Its source is mutable, and QA evidence now records backend, viewport, session context, target URL, and visible state. No pool run was performed.

20 September 2026 · Catalogue expansion · Meaningful change

Dogfood the flow. Do not ask it to invent the design system.

Added Agent Browser Dogfood 0.38.1 for exploratory QA of a runnable frontend when a browser finding needs replayable evidence. It does not read source, enforce a design system, or certify that an interface is good. No pool run was performed.

19 September 2026 · Catalogue expansion · Meaningful change

A browser skill can show the state. It cannot judge the design.

Added Vercel Agent Browser 0.38.1 for a runnable UI state that needs navigation, snapshots, and retained capture. It can create an evidence route for later review, not a design or accessibility verdict. No pool browser run was performed.

18 September 2026 · Catalogue expansion · Meaningful change

A screenshot audit needs a real flow.

Added OpenAI Product Design Audit for a product journey you can capture and inspect. It is not a substitute for source review, and screenshots cannot establish full accessibility compliance. No pool audit was performed.

17 September 2026 · Catalogue expansion · Meaningful change

A visual skill needs a visual proof path.

Added Frontend App Builder for a new high-visibility visual surface when you can approve a concept and compare a browser render. No pool run was performed.

16 September 2026 · Adoption guidance

A portable skill can still be the wrong project configuration.

Added an adoption gate: target agent, scope, source pin, local edits, and update review.
